# Rencana Implementasi: Fitur User Bug Report, Pemisahan Tab Dashboard Cloudflare, dan Integrasi Google Workspace

---

## 1. Fitur User Bug Report (Sisi Pengguna / Ekstensi)
* **Tujuan**: Memungkinkan pengguna mengirim laporan bug/kendala secara langsung dari Sidepanel ekstensi dengan 1-klik, menyertakan deskripsi masalah, konteks sesi, URL halaman aktif, dan snapshot log aktivitas terkini secara otomatis.
* **Komponen yang Dibuat/Dimodifikasi**:
  1. **Tombol Trigger di Header Sidepanel** (`sidepanel/sidepanel.html` & `extension/sidepanel/sidepanel.html`):
     - Menambahkan tombol icon "🐛 Report Bug" di header bar sejajar dengan tombol settings/history.
  2. **Modal Bug Report Dialog** (`sidepanel/sidepanel.html` & `sidepanel/sidepanel.css`):
     - Form input: Judul singkat / Kategori (AI Loop, Tombol Tidak Terklik, UI Error, dsb.), Textarea deskripsi kendala yang dialami.
     - Checkbox otomatis: "Sertakan snapshot log aktivitas & tab aktif terkini" (default: checked).
     - Tombol "Kirim Laporan" dengan loading state dan toast konfirmasi sukses/gagal.
  3. **Logika Pengiriman Telemetri Report** (`sidepanel/sidepanel.js` & `logger.js`):
     - Mengumpulkan metadata: `clientId`, `tabUrl`, `extensionVersion`, `recentLogs` (15 log terakhir dari memori), dan `userAgent`.
     - Melakukan HTTP `POST` ke endpoint Cloudflare: `https://<worker-url>/api/reports`.

---

## 2. Pemisahan Tab di Dashboard Cloudflare (Sisi Developer)
* **Tujuan**: Di URL `/logs` Cloudflare, memisahkan secara visual dan fungsional antara log runtime harian ekstensi dan laporan bug masuk dari pengguna.
* **Komponen yang Dimodifikasi**:
  1. **Backend Storage Buffer & Endpoints** (`index.js` & `functions/api/reports.js`):
     - Menginisialisasi buffer memori terpisah: `globalThis.__PESAT_REPORTS__ = []` (kapasitas 200 laporan).
     - Menyediakan endpoint REST:
       - `GET /api/reports` (mengambil list laporan dengan filter status & search).
       - `POST /api/reports` (menerima payload bug report dari ekstensi).
       - `DELETE /api/reports` (membersihkan / me-resolve daftar laporan).
  2. **Modern Tab Navigation di `/logs` Dashboard** (`index.js` & `public/logs.html`):
     - **Tab 1: 📊 Runtime Logs** (Monitoring aktivitas real-time live polling, filter INFO, AI, ACTION, WARN, ERROR).
     - **Tab 2: 🐛 User Bug Reports** (Tampilan kartu laporan khusus pengguna):
       - Header ringkas: ID Laporan, Waktu Masuk, Kategori, Client ID, URL Tab Terkait.
       - Isi Laporan: Pesan keluhan pengguna.
       - Expandable Section: Snapshot log aktivitas sebelum bug terjadi dan data teknis terkait.
       - Tombol Ekspor JSON & tombol Mark as Resolved.

## 3. Strategi & Solusi Integrasi Google Workspace
* **Tujuan**: Memberdayakan Pesat Agent untuk mengotomatisasi tugas-tugas di Google Workspace (Docs, Sheets, Gmail, Drive) untuk meringankan pekerjaan manusia.

### Pendekatan 1: Direct DOM & Canvas Workspace Automation (Zero-Config / Rekomendasi Utama)
* **Kelebihan**: Tidak memerlukan pembuatan Google Cloud Project atau izin OAuth yang rumit dari user; langsung bekerja pada akun Google yang sudah login di Chrome tab.
* **Kemampuan Otomatisasi**:
  1. **Google Sheets**:
     - Ekstraksi data tabel web / ringkasan artikel, kemudian diubah ke format TSV/CSV dan di-paste otomatis ke sel aktif Google Sheets atau disisipkan baris demi baris.
     - Otomatisasi pengisian formula dan formatting sel via keyboard shortcuts (`Enter`, `Tab`, `Arrow keys`).
  2. **Google Docs**:
     - Memanfaatkan target iframe `.docs-texteventtarget-iframe` dan `document.execCommand("insertText")` untuk menuliskan draf dokumen, proposal, atau hasil rangkuman langsung ke lembar kerja Google Docs.
  3. **Gmail**:
     - Membuka `mail.google.com`, menekan tombol *Compose* (`@eX` / shortcut `c`), mengisi kolom penerima, subjek, serta body email, dan menyiapkan draf email otomatis.
  4. **Google Drive / Google Forms**:
     - Otomatisasi pengisian kuesioner/form Google Forms multi-page secara cerdas.

### Pendekatan 2: Background Google REST API (OAuth 2.0 via `chrome.identity`)
* **Kelebihan**: Eksekusi instan di background tanpa perlu membuka tab browser Google Workspace di depan layar.
* **Integrasi**:
  - Mengonfigurasi `chrome.identity.launchWebAuthFlow` atau `chrome.identity.getAuthToken` dengan scope:
    - `https://www.googleapis.com/auth/spreadsheets`
    - `https://www.googleapis.com/auth/documents`
    - `https://www.googleapis.com/auth/gmail.compose`
  - Menyediakan tool khusus pada prompt AI: `google_sheets_append_row`, `google_docs_create`, `gmail_create_draft`.

### Langkah Konkret untuk Google Workspace:
* Menambahkan Quick Action Chips khusus di Sidepanel:
  - 📊 *Export ke Google Sheets*
  - 📝 *Tulis di Google Docs*
  - ✉️ *Buat Draf Gmail*
* Memperbarui System Prompt & Tool Executor di `content.js` dan `index.js` agar memahami interaksi khusus pada domain `*.google.com`.
