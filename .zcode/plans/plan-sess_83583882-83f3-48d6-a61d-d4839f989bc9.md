### Analisis & Rencana Penyelesaian: AI Berhenti Setelah Klik Compose

#### 1. Penyebab Utama
- **Single-Subtask Breakdown & Premature Finalization**:
  Saat user mengirim prompt panjang, planner LLM gagal mengembalikan multi-step JSON dan jatuh ke fallback 1 subtask. Pada Step 1, ReAct mengeksekusi klik tombol Compose (`@e1`). Karena klik berhasil (`exec.success = true`), subtask #1 ditandai `done` dan sistem langsung memanggil `finalizeTask()`, mengira seluruh tugas selesai.
- **Isi Pesan Tidak Disintesis Jadi Email Formal**:
  Prompt user yang meminta *"tulis draf email formal yang menjelaskan bahwa milestone fitur agentic browser telah selesai 100%"* terputus karena belum sempat dieksekusi oleh langkah ReAct berikutnya.

#### 2. Solusi & Perbaikan
1. **Direct Fast-Path Execution untuk Email Task (`sidepanel/sidepanel.js`)**:
   - Deteksi intent email (`send_email`) di awal `startTask`.
   - Mengambil parameter `{ to, subject, body }` secara presisi.
   - Sintesis isi email formal jika diminta teks formal/resmi, lalu langsung mengeksekusi `send_email` end-to-end (buka compose $\to$ isi penerima $\to$ isi subjek $\to$ tulis body formal).
2. **Prevent Premature Termination di ReAct Loop**:
   - Jika form Compose sudah terbuka di layar, otomatis teruskan ke langkah pengisian form daripada berhenti setelah klik.
