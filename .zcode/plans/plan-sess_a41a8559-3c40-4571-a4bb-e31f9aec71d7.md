# Rencana Desain & Arsitektur: Integrasi 5 Modular Agent Skills (skills.sh Standard) pada Pesat AI Chrome Agent

Berdasarkan analisis arsitektur ekstensi Manifest V3 (Service Worker, Sidepanel ReAct loop, Content Script DOM engine, dan Cloudflare proxy), berikut adalah rancangan integrasi 5 modul `skills/` terisolasi berbasis standar `skills.sh`.

---

## 1. Analisis Kebutuhan & Pemetaan 5 Skills

| # | Skill | Peran Arsitektur di Ekstensi | Komponen Eksekusi | Kebutuhan & Masalah yang Diselesaikan |
|---|---|---|---|---|
| **1** | **Vision & Canvas OCR** (`skills/vision-ocr.js`) | Membaca canvas non-DOM (Google Docs Kix Canvas, PDF viewer, chart/grafik) | `background.js` (tab capture) + LLM Vision API + `content.js` (`click_coords`) | Mengatasi keterbatasan DOM inspector pada halaman canvas seperti Google Docs/Sheets yang tidak memiliki teks HTML biasa. |
| **2** | **Deep Table & Multi-Page Web Scraper** (`skills/web-scraper.js`) | Ekstraksi tabel kompleks & penelusuran pagination otomatis | `content.js` (DOM/ARIA table extractor) + `sidepanel.js` (paging orchestrator) | Mengikis data produk/katalog multi-halaman (misal: Tokopedia, Shopee, portal data) secara berulang hingga selesai. |
| **3** | **Smart Form Inspection & Auto-Fill** (`skills/form-engine.js`) | Inspeksi skema formulir web dan pengisian masal instan | `content.js` (React/Vue synthetic value setter & shadow DOM traversal) | Mengisi formulir panjang dalam 1 round-trip aksi tanpa looping klik & ketik 1-per-1 yang lambat dan rawan gagal. |
| **4** | **Google Workspace REST / MCP Client** (`skills/gworkspace-mcp.js`) | Manipulasi spreadsheet & dokumen langsung via API latar belakang | `background.js` (Google REST v4 / `chrome.identity` token) | Memodifikasi Google Sheets & Docs secara presisi tanpa bergantung pada manipulasi canvas keyboard/mouse DOM yang rapuh. |
| **5** | **Document & Export Engine** (`skills/doc-export.js`) | Standardisasi pembuatan file CSV, TSV, Markdown, dan draf dokumen | `sidepanel.js` (RFC 4180 encoder & renderer) + `background.js` (`chrome.downloads`) | Menghasilkan file unduhan rapi, konsisten, dan terstruktur untuk data hasil riset / komparasi. |

## 2. Arsitektur Modular: `SkillRegistry`

Struktur direktori baru:
```text
skills/
├── skill-registry.js      # Loader terpusat untuk mendaftarkan tools & rules ke LLM
├── vision-ocr.js          # Skill 1: Screenshot, canvas bbox, coordinate mapping
├── web-scraper.js         # Skill 2: Table heuristic, pagination detector, dataset aggregator
├── form-engine.js         # Skill 3: Form discovery, input classification, React/Vue value setters
├── gworkspace-mcp.js      # Skill 4: Google Sheets v4 & Docs v1 background REST caller
└── doc-export.js          # Skill 5: CSV/TSV RFC 4180 exporter, JSON converter, report builder
```

### Mekanisme Kerja Modular:
1. **Pendaftaran Dinamis (`SkillRegistry.getTools()`)**:
   Setiap modul skill mengekspor definisi OpenAI-compatible tool call (`name`, `description`, `parameters`) dan fungsi `execute()`.
2. **Injeksi Panduan Prosedural (`SkillRegistry.getSystemRules()`)**:
   Aturan prosedural spesifik skill digabungkan ke `ai-engine.js` saat ReAct loop aktif.
3. **Eksekusi Aksi Tanpa Mengotori Core Loop**:
   Ketika LLM memanggil nama aksi dari skill (misal `scrape_multipage_table` atau `autofill_form_fields`), `SkillRegistry` meneruskannya ke modul yang bersangkutan.

## 3. Rincian Teknis Implementasi Tiap Modul

### Skill 1: Vision & Canvas OCR (`skills/vision-ocr.js`)
* **Tools yang Disediakan**: `ocr_inspect_canvas`, `click_canvas_text`
* **Alur Kerja**:
  1. `content.js` mendeteksi koordinat elemen `<canvas>` (misal Google Docs/PDF).
  2. `background.js` mengambil tangkapan layar area aktif via `chrome.tabs.captureVisibleTab`.
  3. Mengirimkan gambar ke endpoint Vision (`pesat-pro` / vision model) untuk mendeteksi teks dan bounding box koordinat (x, y).
  4. Menerjemahkan koordinat target ke aksi fisik `click_coords(x, y)` di `content.js`.

### Skill 2: Deep Table & Multi-Page Web Scraper (`skills/web-scraper.js`)
* **Tools yang Disediakan**: `extract_table_data`, `scrape_multipage_table`
* **Alur Kerja**:
  1. Deteksi elemen tabel berbasis `<table>`, `[role="grid"]`, maupun list kartu berulang (*card grids*).
  2. Deteksi tombol pagination otomatis (`rel="next"`, tombol dengan angka berikutnya, atau text *"Next"* / *"Berikutnya"*).
  3. `sidepanel.js` menjalankan loop: Ekstrak baris halaman aktif $\to$ klik halaman berikutnya $\to$ `WAIT_FOR_DOM_STABLE` $\to$ ulangi hingga batas maksimal halaman yang diminta.
  4. Menyajikan dataset teragregasi langsung ke kartu ekspor CSV.

### Skill 3: Smart Form Inspection & Auto-Fill (`skills/form-engine.js`)
* **Tools yang Disediakan**: `inspect_form_fields`, `autofill_form_batch`
* **Alur Kerja**:
  1. Memindai form aktif dan mengembalikan schema field: `{ id, name, label, type, placeholder, options }`.
  2. Model AI memetakan data pengguna ke schema form dalam satu panggilan API.
  3. Mengisi seluruh field sekaligus menggunakan *native setter override* (`Object.getOwnPropertyDescriptor(HTMLInputElement.prototype, 'value').set`) agar state framework modern (React, Vue, Angular) langsung ter-update tanpa error validasi.

### Skill 4: Background Google Workspace REST/MCP (`skills/gworkspace-mcp.js`)
* **Tools yang Disediakan**: `gworkspace_append_sheet_data`, `gworkspace_read_sheet`, `gworkspace_write_doc`
* **Alur Kerja**:
  1. Memeriksa `googleAuthToken` dari `chrome.storage.local` (hasil login Google OAuth yang sudah aktif).
  2. Jika token tersedia: Panggilan pembuatan/pengisian Google Sheets menggunakan Google Sheets API v4 (`PUT https://sheets.googleapis.com/v4/spreadsheets/{id}/values/{range}`) langsung di latar belakang, tanpa bergantung pada paste canvas.
  3. Jika token tidak tersedia: Menjalankan fallback canvas paste / formula bar yang sudah ada di `content.js`.

### Skill 5: Document & Export Engine (`skills/doc-export.js`)
* **Tools yang Disediakan**: `export_dataset_to_csv`, `format_rich_document`
* **Alur Kerja**:
  1. Parsing dataset array/JSON ke format CSV standar RFC 4180 (penanganan tanda petik ganda, koma, dan karakter baris baru).
  2. Konversi Markdown ke HTML Table ber-styling inline untuk clipboard Google Docs / Microsoft Word.
  3. Memicu aksi unduhan otomatis via `chrome.downloads.download` di `background.js`.

## 4. Rencana Langkah Eksekusi (Implementation Steps)

1. **Step 1: Pembuatan Folder & Modul Skills**
   * Buat folder `skills/` di root dan `extension/skills/`.
   * Implementasikan kelima file skill: `vision-ocr.js`, `web-scraper.js`, `form-engine.js`, `gworkspace-mcp.js`, dan `doc-export.js`.
   * Buat `skills/skill-registry.js` sebagai pusat registrasi dan router eksekusi tool.

2. **Step 2: Integrasi ke Core Agent Engine**
   * Hubungkan `skill-registry.js` ke `sidepanel/sidepanel.html` dan `sidepanel.js`.
   * Perbarui `ai-engine.js` agar menyertakan tools dari `SkillRegistry` ke dalam payload model AI.

3. **Step 3: Penyambungan Komunikasi Background & Content Script**
   * Daftarkan handler aksi `EXECUTE_SKILL` pada `background.js` dan listener di `content.js`.

4. **Step 4: Sinkronisasi & Pengujian Mandiri**
   * Sinkronisasi seluruh file ke direktori `extension/`.
   * Jalankan validasi sintaks JavaScript menyeluruh (`node -c`).
   * Uji coba eksekusi perintah (ekstraksi data multi-page, pengisian form instan, dan pembuatan tabel Docs/Sheets).
